Open that on the computer and carry on from step 1. This page cannot do it for you: it talks to the machine it is open on, and right now that is this phone.

1 Install it on this computer

The board is a screen on a cable. A small program on your computer reads the figures Claude Code and Codex have already written to disk and sends them down. Nothing to sign in to.

Paste that into Terminal and press return. It lists everything it will change before changing anything, and overwatch uninstall puts it all back.

Use the command, not a download link. macOS quarantines anything a browser downloads and then refuses to run it — “cannot be opened because the developer cannot be verified”. curl sets no quarantine flag, so the line above just works.

2 Plug the board in

Any USB port, any cable that carries data — a charge-only cable powers the screen and is never seen by the computer, which is the single most common reason a board looks dead.

The dials fill within a few seconds of your next Claude Code or Codex session.
