Overwatch

Your Claude Code and Codex usage, as two live dials on your desk.

The board does nothing on its own. It is a screen on a USB cable — a small program on your computer reads the figures Claude Code and Codex already write to disk, and sends them down. Three steps, once.
1

Install it

One line. Paste it into Terminal (macOS, Linux) or PowerShell (Windows) and press return.

# macOS, Apple silicon
curl -fsSL https://github.com/SleepyUnicon/Overwatch/releases/latest/download/overwatch-macos-arm64.tar.gz | tar xz && ./overwatch/overwatch
# macOS, Intel
curl -fsSL https://github.com/SleepyUnicon/Overwatch/releases/latest/download/overwatch-macos-x86_64.tar.gz | tar xz && ./overwatch/overwatch

# Linux
curl -fsSL https://github.com/SleepyUnicon/Overwatch/releases/latest/download/overwatch-linux-x86_64.tar.gz | tar xz && ./overwatch/overwatch
:: Windows
curl.exe -fsSL -o overwatch.zip https://github.com/SleepyUnicon/Overwatch/releases/latest/download/overwatch-windows-x86_64.zip && tar -xf overwatch.zip && .\overwatch\overwatch.exe

It lists everything it is about to change before changing anything. The only file it edits is ~/.claude/settings.json, and overwatch uninstall puts it all back.

Use the command, not your browser. macOS quarantines anything a browser downloads, and Gatekeeper then refuses to run it — "cannot be opened because the developer cannot be verified". These builds are ad-hoc signed rather than notarised, so that refusal is expected. curl sets no quarantine flag and the command above just works. If you did download it in a browser, clear the flag with xattr -d com.apple.quarantine overwatch/overwatch.
2

Open the setup page

The installer prints a link to it when it finishes, and it stays up for as long as Overwatch is running:

http://127.0.0.1:8730

That page sets the launcher's six tiles and tells you whether the board is being seen. It runs on your own machine and is reachable only from it.

3

Plug the board in

Any USB port. The dials fill within a few seconds of the first Claude Code or Codex session.

On Windows the board needs a driver Windows does not ship. The installer puts it in for you — it is the step that asks for a permission prompt.

✓

Using it

Swipe between five pages. Usage in the middle, music to the left, the launcher to the right, settings above, the face below. The launcher's six tiles are set from a page the app serves at http://127.0.0.1:8730.

The screen says "Waiting for the app on your computer"

That is the board telling you step 2 has not happened yet, or the program is not running. Run overwatch status — it says in one line whether the service is up, whether Claude Code and Codex are being read, and how old the figures are.

The board never appears

Unplug it and plug it back in first; the app finds it again by itself. If that does not do it, try a different cable — a charge-only cable carries power but no data, so the board lights up and is never seen. On Windows, run %USERPROFILE%\.overwatch\bin\overwatch.exe driver.

Nothing was sent anywhere, was it?

No. It reads files Claude Code and Codex have already written to your own disk and sends them down a cable to a screen on your desk. There is no account, no network call, and nothing to sign in to.
