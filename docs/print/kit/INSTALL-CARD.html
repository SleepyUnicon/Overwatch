OVERWATCH
Setting it up — about two minutes

This little screen shows how much of your Claude Code and Codex usage you have left, as two dials, always in view. It plugs into your computer over USB. There is no account to make, no WiFi to set up, and nothing running in the cloud.

1Open a terminal and paste one line

Pick the line for your computer. It downloads the program and sets everything up — you can delete the folder it leaves behind afterwards.

macOS — Apple Silicon (M1 and later)

curl -fsSL https://github.com/SleepyUnicon/Overwatch/releases/latest/download/overwatch-macos-arm64.tar.gz | tar xz && ./overwatch/overwatch

macOS — Intel

curl -fsSL https://github.com/SleepyUnicon/Overwatch/releases/latest/download/overwatch-macos-x86_64.tar.gz | tar xz && ./overwatch/overwatch

Linux

curl -fsSL https://github.com/SleepyUnicon/Overwatch/releases/latest/download/overwatch-linux-x86_64.tar.gz | tar xz && ./overwatch/overwatch

Windows — PowerShell

curl.exe -fsSL -o overwatch.zip https://github.com/SleepyUnicon/Overwatch/releases/latest/download/overwatch-windows-x86_64.zip && tar -xf overwatch.zip && .\overwatch\overwatch.exe

Not sure which? Open sleepyunicon.github.io/Overwatch and the page offers the right one.

Paste the command — do not click a download link

macOS marks anything downloaded by a browser as untrusted and refuses to run it: "cannot be opened because the developer cannot be verified". The command above does not trip that. If you have already hit it, delete what you downloaded and use the command instead.

2Plug the screen in

Over USB, to the same computer. It finds itself — there is nothing to choose. The setup screen on the panel steps aside within a few seconds, and the dials come up.

3Open Claude Code once

The numbers come from Claude Code's own status line, so nothing appears until it has drawn one. Open it, run anything, and the dials fill in.

You need Claude Code 2.1.100 or newer. Older versions do not publish the usage figures at all.

Using it

Swipe left or right music, dials, app launcher
Tap the gearsettings — light or dark theme
Tap the little faceit has moods
Leave it alonethe face takes over the screen

If something looks wrong

Panel says "Link the PC daemon" run overwatch status in a terminal
Dials are emptyopen Claude Code once
Nothing happens when plugged in try a different USB cable. Many are charge-only.

It updates itself from then on — both halves — and asks before it does. To remove it completely, overwatch uninstall puts everything back.
